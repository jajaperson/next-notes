# Emptyset axiom

The **Emptyset Axiom** is a possible axiom in [Material set theory](Material%20set%20theory.md): #m/def/set/zf
$$
\begin{align*}
(\exists \shood o)(\nexists x)[x \in o]
\end{align*}
$$
which is to say, there exists a set with no elements,
which by the [Axiom of Extensionality](Axiom%20of%20Extensionality.md) is unique and may be called $\0$, the [empty set](Empty%20set.md).
