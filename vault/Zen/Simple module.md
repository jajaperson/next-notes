# Simple module

A [module](Module.md) $M \in \lMod R$ is **simple** or **irreducible** iff it has no nontrivial proper [Submodule](Submodule.md). #m/def/module

## Properties

* [Schur's lemma](Schur's%20lemma.md) states that any nonzero homomorphism between simple modules is an isomorphism.
