# Indecomposable module

A module $M \in \lMod R$ is **indecomposable** iff it not the [direct sum](Direct%20sum%20of%20modules.md) of two nontrivial [submodules](Submodule.md). #m/def/module
Note this does not imply $M$ is a [simple module](Simple%20module.md).
