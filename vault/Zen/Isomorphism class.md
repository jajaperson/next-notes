# Isomorphism class

An isomorphism class is a type of [equivalence class](Equivalence%20relation.md#equivalence-class) that groups objects within a [category](Category.md) with other objects they are isomorphic to. #m/def/cat

An example of isomorphism class in the category $\Set$ is [Cardinality](Cardinality.md).
