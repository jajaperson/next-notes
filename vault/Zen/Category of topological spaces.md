# Category of topological spaces

The **category of topological spaces** $\Top$ is the [category](Category.md) where each object is a [topological space](Topological%20space.md) and each morphism is a [continuous map](Continuity.md). #m/def/topology

 > 
 > \[!check\]- Well defined category
 > 
 > * Composition of continuous maps yields a continuous map
 > * The identity is always continuous
 > * Function composition is already associative

## Properties

### Universal constructions

* The [initial object](Initial%20and%20terminal%20objects.md) of $\Top$ is $\0$ with the unique topology
* The [terminal object](Initial%20and%20terminal%20objects.md) of $\Top$ is $\{ * \}$ with the unique topology

### Morphisms

* [Regular monomorphisms in the category of topological spaces](Regular%20monomorphisms%20in%20the%20category%20of%20topological%20spaces.md)
