# Division ring

A **division ring**[^de][^alt] is a [ring](Ring.md) in which every nonzero element is a [multiplicative unit](Units%20and%20zero-divisors.md).
See also [Division algebra](Division%20algebra.md).

[^de]: German *Divisionsring*.

[^alt]: Also called a **skew field** (German *Schiefkörper*). I prefer the term division ring because a division ring is a ring, but a skew field is not necessarily a field.
