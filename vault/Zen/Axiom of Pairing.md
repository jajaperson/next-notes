# Axiom of Pairing

The **Axiom of Pairing** is a possible axiom in [Material set theory](Material%20set%20theory.md): #m/def/set/zf
$$
\begin{align*}
(\forall x,y)(\exists \shood A)[z \in A \iff z = x \lor z = y]
\end{align*}
$$
which is to say, for any two objects there is a set whose only elements are those two objects.
It follows from the [Axiom of Extensionality](Axiom%20of%20Extensionality.md) that such a **doubleton** $A$ is unique, which we denote $\{ x,y \}$.
