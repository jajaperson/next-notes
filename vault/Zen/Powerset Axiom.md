# Powerset Axiom

The **Powerset Axiom** is a possible axiom of [Material set theory](Material%20set%20theory.md) asserting the existence of the *powerset*: #m/def/set/zf
$$
\begin{align*}
(\forall\shood A)[\exists \shood P](X \in P \iff \shood(X) \land X \sube A)
\end{align*}
$$
where $X \sube A$ denotes [subset](Subset.md),
which is to say, for any set $A$ there exists a set of all its subsets $P$,
which by the [Axiom of Extensionality](Axiom%20of%20Extensionality.md) is unique and we denote $\mathcal{P}(A)$ and call the *powerset*.
